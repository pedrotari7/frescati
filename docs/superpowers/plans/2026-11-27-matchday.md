# Matchday implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A game-day programme (odds, form, rivalry, storylines) and a per-player full-time card that takes over the season home after a result and can be shared as an image.

**Architecture:** Two pure modules in `shared/` (`matchday.ts`, `fullTime.ts`) compute everything from the rating ledger, the lineup and the result document. Two new routes under the game render them. A takeover hook on the season home, modelled on `useRecapTakeover`, opens the card. A canvas module turns the card into a PNG for the share sheet. No backend, rules or stored fields.

**Tech Stack:** Next.js 15 App Router, React 19, StyleX, Firestore client SDK, Vitest + Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-27-matchday-design.md`

## Global constraints

- No change under `backend/src`, to `firestore.rules` or `storage.rules`, and no new field on any document.
- No new npm dependency.
- Colours only from `frontend/app/tokens.stylex.ts`. No hex in components, including the canvas, which reads computed colours off rendered elements.
- Styling is StyleX (`stylex.create` + `stylex.props`), hovers inside `bp.hover`, conditional styles as extra arguments.
- Arrow-function components, default export at the bottom, props typed inline. `import type` for types.
- Every new screen sets `backHref` on its loading, error and missing branches as well as the loaded one.
- Rating movement always goes through `RatingMovement` / `toDisplayRating`, never its own rounding.
- All copy, JSDoc, comments and test names go through the `unslop` skill before commit. No em dashes, straight quotes, sentence case.
- Only export what another file imports. The fallow gate fails on an unused export, a duplicate block or a function over cyclomatic 20 / cognitive 15. Run `pnpm fallow:audit` before each commit.
- Reduced motion: every animation is cut short by `globals.css`; confetti is not rendered at all when `prefers-reduced-motion: reduce` (reuse `Confetti`, which already does this).

## Review focus

1. **A ledger entry with no `teams` map** (old games). The rivalry and the form guide must skip it rather than misread teammates as opponents. Test in Task 1.
2. **An unrated player in the pool or on the card** (`rating` undefined, `before: null`). Odds use `lineup.elos`, which already holds a seed, and storylines skip milestone for them. Test in Task 1. The card reads `RatingDelta` from the result, which always has numbers.
3. **A shared first place.** Form reads D, the card says "level first", and the table-move highlight still compares 0-indexed competition positions. Tests in Tasks 1 and 2.
4. **Storage that throws** (Safari private mode). The takeover must not fire when it cannot record that it fired, and the card screen must still render. Test in Task 6.
5. **A replayed or corrected game after the card was seen.** `finalisedAt` on the ledger entry changes on a replay, so the seen mark compares timestamps, not ids, and a replay of an already-seen game older than the mark does not re-trigger. Test in Task 2 (`pickFullTimeTakeover` with `seenAt` equal to and after `finalisedAt`).
